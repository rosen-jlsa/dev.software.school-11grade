# Software Development Exercises — 11th Grade

School software development material and practice code. The repository contains C# preparation files, dated exercise folders, a calculator exercise, and early demos.

## Where to start

- `preparation-for-test.cs` and `preparation-fot-test-0.2.cs` — C# practice files.
- `calulater/` — calculator exercise.
- `first-Demo/` and dated folders — additional classroom work.

These are independent exercises rather than one application. Open the relevant folder or source file in your editor and run it with the tools required by that exercise.
